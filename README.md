# Gestión Pescadería Luque

Aplicación web para llevar la caja diaria de la Pescadería Luque. Funciona en ordenador, tablet y móvil, sin instalar nada.

## Qué hace (versión 1)

- **Apertura de caja**: fondo inicial en efectivo (sugiere el fondo que se dejó el día anterior).
- **Cierre de caja**: ventas en efectivo, tarjeta y Bizum (según ticket Z / datáfono), gastos pagados de caja, recuento de efectivo (con contador de billetes y monedas) y fondo para el día siguiente.
- **Cuadre automático**: calcula el efectivo que debería haber y si falta o sobra dinero.
- **Resumen mensual**: totales de ventas por forma de pago, gastos, media diaria y descuadre acumulado.
- **Copia de seguridad**: descargar y restaurar los datos en un archivo.

## Cómo usarla

Abre `index.html` en el navegador. Los datos se guardan en el propio dispositivo (no se comparten entre dispositivos todavía).
